# SIGMOD 2027 repository notes

The SIGMOD 2027 research-track call states that authors are expected to make code, data, scripts, and notebooks available when possible; the artifact link supplied with a research submission must preserve double anonymity. The call also warns that anonymity violations in an associated external codebase can cause rejection.

Official research-track call:
https://2027.sigmod.org/calls_papers_sigmod_research.shtml

SIGMOD Availability & Reproducibility Initiative:
https://reproducibility.sigmod.org/

This repository therefore separates the anonymous public artifact from author identity and from non-observed planning material.
